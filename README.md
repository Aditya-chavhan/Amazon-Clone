# 🛒 Amazon Clone (Frontend Project)

![Amazon Clone Logo](amazon%20ka%20log.png)

## 📌 Overview

This project is a **frontend clone of Amazon’s homepage**, built using **HTML and CSS**. It replicates the layout, design, and basic UI components of Amazon, including the navbar, product sections, and footer.

It is designed to improve **frontend development skills** and understanding of real-world UI structuring.

---

## 🚀 Features

* 🧭 Fully structured **navigation bar**
* 🔍 Search bar UI similar to Amazon
* 📦 Product category sections (grid layout)
* 🖼️ Responsive product cards with images
* 📍 Delivery location section
* 🛒 Cart and account UI
* 📑 Footer with multiple sections
* 🎨 Clean and modern styling using CSS

---

## 🛠️ Tech Stack

* **HTML5** – Structure of the webpage 
* **CSS3** – Styling and layout design 
* **Remix Icons** – Icons used in UI
